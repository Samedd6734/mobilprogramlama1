# Dart'a Giriş

Bu klasör, Mobil Programlama 1 dersi kapsamında **Dart'a Giriş** konusu için hazırlanan çalışmaları içerir. Konu materyalleri dört bölümde düzenlenmiştir: çeviri, sunum, uygulama ve soru-cevap.

## Klasör Yapısı

```text
01-dart-anatomy/
├── ceviri/
│   ├── 2026-guz-kodbu...md
│   └── 2027-guz-yenitakim.md
├── sunum/
│   ├── 2026-guz-kodbu...pdf
│   └── 2027-guz-yenitakim.pdf
├── uygulama/
│   ├── v1-2026-kodbu.../
│   │   ├── main.dart
│   │   └── README.md
│   └── v2-2027-yenitakim/
│       ├── main.dart
│       └── README.md
└── soru-cevap/
    ├── 2026-guz-kodbu...md
    └── 2027-guz-yenitakim.md
```

> Not: Yukarıdaki dosya adlarındaki `...` işaretleri, klasör yapısını kısa göstermek için kullanılmıştır. Kendi dosyalarının gerçek adlarını değiştirmene gerek yoktur.

## Bölümlerin Açıklaması

- **`ceviri/`**: Dart'a Giriş konusuyla ilgili çeviri ve yazılı konu notları.
- **`sunum/`**: Konuyu anlatmak için hazırlanan PDF sunumları.
- **`uygulama/`**: Dart kod örnekleri ve uygulama dosyaları. Her sürüm kendi klasöründe bulunur.
- **`soru-cevap/`**: Konuyla ilgili sorular, cevaplar ve tekrar çalışmaları.

## Uygulamayı Çalıştırma

Dart SDK bilgisayarında kuruluysa, ilgili uygulama klasörüne girip `main.dart` dosyasını şu komutla çalıştırabilirsin:

```bash
dart run main.dart
```
